# Party leader cutouts

The party pills show a small cutout that slides up from behind on hover (and when
selected). Until a real image is provided, each shows a labeled silhouette placeholder.

To use a real photo, drop a **transparent-background PNG cutout** here named after the
leader (lowercase), and it will be picked up automatically:

```
public/leaders/grindeanu.png    (PSD)
public/leaders/simion.png       (AUR)
public/leaders/georgescu.png    (AUR — comes in front)
public/leaders/bolojan.png      (PNL)
public/leaders/siegfried.png    (PNL — comes in front)
public/leaders/fritz.png        (USR)
public/leaders/sosoaca.png      (SOS)
public/leaders/kelemen.png      (UDMR)
```

Only use images you have the rights to. Square-ish head-and-shoulders cutouts (~256×256,
transparent background) look best in the circular frame. POT intentionally shows
"It's gone!" and Minoritati has no cutout.
